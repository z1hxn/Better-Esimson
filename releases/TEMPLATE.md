# Better Esimson vX.Y.Z — 릴리스 제목

이번 릴리스의 핵심 내용을 한두 문장으로 소개합니다.

> Chrome 웹 스토어가 아닌 ZIP 파일로 배포됩니다. 아래 설치 방법을 따라 압축을 푼 폴더를 Chrome에 등록해 주세요.

## 주요 변경 사항

### 추가

- 새로 추가된 사용자 기능

### 변경

- 달라진 화면이나 동작

### 수정

- 해결한 오류나 호환성 문제

## 설치 방법

1. 아래 Assets에서 `better-esimson-vX.Y.Z.zip`을 다운로드합니다.
2. ZIP 파일을 원하는 위치에 **완전히 압축 해제**합니다.
3. Chrome 주소창에 `chrome://extensions`를 입력합니다.
4. 오른쪽 위의 **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
6. `manifest.json`이 들어 있는 폴더를 선택합니다.
7. `https://www.esimson.com`을 열거나 새로고침합니다.

## 기존 사용자 업데이트

1. 새 버전 ZIP을 내려받아 압축을 풉니다.
2. 기존 확장 폴더의 파일을 새 파일로 교체합니다.
3. `chrome://extensions`에서 Better Esimson 카드의 **새로고침** 버튼을 누릅니다.

> 압축 해제한 폴더를 이동하거나 삭제하면 Chrome이 확장을 불러오지 못할 수 있습니다.

## 알려진 문제

- 알려진 문제가 없다면 `현재 확인된 주요 문제는 없습니다.`라고 적습니다.
