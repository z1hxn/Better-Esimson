# Better Esimson v1.4.0 — 첫 공개 릴리스

심슨어학원의 오래된 웹 화면을 더 깔끔하고 편리하게 바꾸는 Chrome 확장 프로그램, **Better Esimson**의 첫 공개 릴리스입니다.

> 이 릴리스는 Chrome 웹 스토어가 아닌 ZIP 파일로 배포됩니다. 아래 설치 방법을 따라 압축을 푼 폴더를 Chrome에 등록해 주세요.

## 주요 기능

- 심슨어학원 홈, 로그인 화면과 학생시스템을 현대적인 UI로 재구성
- 학생시스템 대시보드와 학습 캘린더 제공
- 성적 조회, 성적 상세, 문항별 결과와 자주장 분석 노트 지원
- 나의 포인트, 선생님 상담, 포트폴리오와 My 보카 접근 개선
- 숙제 상세, Self Check, 온라인 보카·리스닝 및 과제 버튼 연동
- 전용 화면이 없는 MY심슨 페이지에도 공통 학생시스템 헤더와 사이드바 적용
- 새 디자인과 기존 디자인 전환, 다크 모드 및 플로팅 설정 제공
- 자동 Self Check와 로그아웃 확인 옵션 제공
- 첫 실행 온보딩과 화면 스타일 선택 지원
- 홈·학생시스템 키보드 단축키 제공

## v1.3.51에서 개선된 점

- 온보딩의 기존 UI·새 디자인 비교 이미지가 표시되지 않던 문제를 수정했습니다.
- 비교 이미지를 확장 리소스에서 직접 표시하고, 실제 로드 실패 시에만 대체 화면을 사용하도록 안정화했습니다.

## 설치 방법

1. 아래 Assets에서 `v1.4.0.zip`을 다운로드합니다.
2. ZIP 파일을 원하는 위치에 **완전히 압축 해제**합니다.
3. Chrome 주소창에 `chrome://extensions`를 입력합니다.
4. 오른쪽 위의 **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
6. `manifest.json`이 들어 있는 압축 해제 폴더를 선택합니다.
7. `https://www.esimson.com`을 열거나 새로고침합니다.

## 업데이트 방법

웹 스토어 밖에서 설치한 확장은 자동 업데이트되지 않습니다.

1. 새 버전 ZIP을 다운로드하고 압축을 풉니다.
2. 기존 확장 폴더의 파일을 새 파일로 교체하거나 새 폴더를 준비합니다.
3. `chrome://extensions`에서 Better Esimson 카드의 **새로고침** 버튼을 누릅니다.
4. 새 폴더를 사용했다면 기존 확장을 제거한 뒤 새 폴더를 다시 로드합니다.

> 압축 해제한 폴더를 이동하거나 삭제하면 Chrome이 확장을 불러오지 못할 수 있습니다.

## 참고 사항

- Better Esimson은 심슨어학원의 공식 확장 프로그램이 아닌 개인 프로젝트입니다.
- 일부 구형 페이지는 원본 콘텐츠를 새 공통 레이아웃 안에 표시합니다.
- 사이트 구조가 변경되면 일부 기능이 일시적으로 동작하지 않을 수 있습니다.
- 문제 제보와 제안: [GitHub Issues](https://github.com/z1hxn/Better-Esimson/issues)
