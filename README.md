# Better Esimson

심슨어학원 웹사이트의 콘텐츠와 기존 ASP.NET 동작은 유지하면서 화면을 현대적으로 다시 구성하는 Chrome 확장 프로그램입니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 폴더(`Better Esimson`)를 선택합니다.
5. `https://www.esimson.com`을 새로고침합니다.

현재 홈(`/`, `/index.aspx`)과 학생시스템의 출결·과제관리(`/mypage/sub09_02.aspx`), 성적조회 및 상세 결과(`/mypage/sub09_12.aspx`, `/mypage/sub09_12_view_mogosa.aspx`), 나의포인트(`/mypage/sub09_06.aspx`)에 새 디자인이 적용됩니다. 모든 페이지 오른쪽 아래의 Better Esimson 버튼에서 새 디자인을 켜거나 끌 수 있으며, 선택은 브라우저에 저장됩니다.
